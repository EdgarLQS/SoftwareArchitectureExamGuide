# 07 AI 案例考试速记卡

## 卡片 1：AI 系统生命周期

```text
采集 → 清洗标注 → 训练/微调 → 评估 → 压缩优化
→ 部署 → 推理服务 → 监控反馈治理
```

## 卡片 2：云端、边缘、端侧

```text
云端：算力强、集中维护、易扩展；依赖网络、带宽和隐私成本高
边缘：靠近数据、低延迟、减少回传；节点资源和运维有限
端侧：隐私较好、延迟低、可离线、省带宽；算力和存储受限
```

## 卡片 3：资源池

```text
集中式：简单但单点和扩展风险较明显
分布式：可用性、扩展性较强但管理复杂
混合式：集中治理 + 分布调度，适合云边端协同
```

```text
资源抽象：CPU/GPU/NPU 统一表示
动态调度：按负载、优先级、延迟和能耗分配
安全隔离：虚拟化、容器、配额和权限控制
```

## 卡片 4：AI for OS / OS for AI

```text
AI for OS：AI 增强 OS
调度、调优、运维、交互、数据流动

OS for AI：OS 支撑 AI
算力、推理加速、可靠性、安全隔离、云边端协同
```

## 卡片 5：模型优化

```text
量化：降低精度，减小体积和计算量，可能损失精度
剪枝：删除不重要参数，减少规模，可能影响能力
蒸馏：大模型教小模型，降低部署成本，能力有损失
推理加速：优化算子、硬件和运行时，依赖部署平台
```

## 卡片 6：RAG 与知识图谱

```text
文档 → 切分 → Embedding → 向量检索 → 拼接上下文
→ 大模型生成 → 引用、校验和审计

RAG：文档检索和上下文增强
知识图谱：实体关系和结构化推理
可组合：向量检索找语义，图谱约束关系
```

## 通用答题模板

```text
定义：对象 + 机制 + 问题 + 限制
分类：类别 + 作用对象 + 核心目标 + 理由
选型：场景约束 + 方案 + 理由 + 代价
架构：组成 + 数据流 + 质量保障
```
