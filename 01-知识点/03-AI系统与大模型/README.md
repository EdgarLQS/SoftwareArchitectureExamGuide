## 课程路线

```text
AI 基础概念
  ↓
数据 → 训练/微调 → 评估 → 压缩优化 → 部署 → 推理服务
  ↓                         ↓
监控、反馈与治理       云端 / 边缘 / 端侧 / 异构资源池
  ↓                         ↓
RAG / 向量数据库       AI for OS / OS for AI
  ↓
真题 → 变式题 → D+21 完整案例
```
