# AI 案例一页速查

## 一条主线

```text
数据 → 训练/微调 → 评估 → 优化 → 部署 → 推理 → 监控治理
```

## 三个最容易混淆的判断

| 题目 | 结论 |
|---|---|
| 端侧 AI 优势 | 隐私、低延迟、离线、省带宽；不是端侧自行训练和蒸馏 |
| AI for OS | AI 优化 OS 的调度、运维、交互和数据流动 |
| OS for AI | OS 提供算力、加速、隔离、可靠性和云边端协同 |

## 四种模型优化

```text
量化 = 降低精度
剪枝 = 删除不重要参数
蒸馏 = 大模型教小模型
推理加速 = 优化算子、运行时和硬件
```

## RAG

```text
文档切分 → 向量化 → 向量检索 → 拼接上下文
→ 大模型生成 → 校验、引用、权限过滤
```

## 作答顺序

```text
先结论 → 解释概念 → 结合题干 → 给出方案
→ 写优势和限制 → 补充指标或治理措施
```
