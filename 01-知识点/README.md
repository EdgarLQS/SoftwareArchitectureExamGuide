## 三、长文迁移规则

每篇知识长文将分三步处理：

```text
建立独立核验说明
→ 标记来源、版本、绝对化结论和技术风险
→ 在可控范围内直接重构原文并加入当前清单
```

核验重点：

- 软件或协议版本是否变化；
- 固定性能数字是否缺少测试条件；
- “一定、完全、绝对、唯一”等结论是否成立；
- 示例代码是否具备异常、并发和安全边界；
- 历年考频统计是否受到缺题和重构资料影响；
- AI 辅助内容是否经过人工技术复核；
- 是否与当前论文记忆卡和案例专题口径一致。
