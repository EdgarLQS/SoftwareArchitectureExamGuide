Lesson 06 · 90—120 分钟

为什么常用图数据库？爬虫为什么用异步？

把“数据关系复杂”和“I/O 等待多”分别对应到架构选择上。

图数据库选型

当实体很多、关系复杂、查询经常沿关系走多跳时，节点—关系—属性模型更直观，路径查询也更自然。它不是在所有场景都替代关系数据库。

爬虫四组件

URL 调度器 → 网页下载器 → 内容解析器 → 数据存储器
       └──────── URL 去重 / 重试 / 限速 ────────┘

异步 I/O

发起网络请求后不阻塞等待，先调度其他请求，等结果到达后再处理。它适合 I/O 密集型场景，但会增加异常、超时和资源控制复杂度。

主动练习

用三句话回答：医院知识图谱为什么适合图数据库？网页下载为什么适合异步 I/O？各写一个风险。

查看参考答案

医药实体和关系复杂，需要多跳关系查询；网页下载主要等待网络响应，异步可以减少等待并提高并发；风险可写图查询失控、数据质量不一致、请求过多触发限流、超时重试导致资源耗尽等。
