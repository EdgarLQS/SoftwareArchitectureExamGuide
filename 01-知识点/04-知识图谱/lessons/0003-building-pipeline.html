Lesson 03 · 90—120 分钟

从数据到知识：七阶段流程

今天要建立一条不会乱序的考试主线。

本课胜利：能默写“采集—清洗—抽取—表示—融合—存储—应用”。
数据源 → 采集 → 清洗 → 抽取 → 表示 → 融合 → 存储 → 应用
阶段回答的问题
采集数据从哪里来？
清洗数据是否干净、统一？
抽取文本里有哪些实体、关系和属性？
表示如何编码为三元组、RDF 或属性图？
融合同一实体如何合并？冲突如何处理？
存储如何持久化和查询？
应用如何问答、检索、推荐或决策？

主动练习

把“北京协和医院治疗肺炎，医院等级为三级甲等”分别放入哪个阶段？

查看参考答案

识别“北京协和医院、肺炎”属于抽取；得到“治疗”关系和“医院等级”属性也属于抽取；把结果写成三元组属于表示；后续写入图数据库属于存储。

真题提醒：知识抽取是从数据中发现结构；知识表示是把已发现的知识编码成结构。两者不是同义词。

采集层也要会看图

流程题中，数据采集常展开为 URL 调度器 → 网页下载器 → 内容解析器 → 数据存储器，旁路配合 URL 去重。网页下载属于 I/O 密集场景，可以用异步 I/O 减少等待，但仍要控制超时、重试、限速和失败队列。
