## 课程路线

```text
图是什么
  ↓
实体、关系、属性、三元组
  ↓
采集 → 清洗 → 抽取 → 表示 → 融合 → 存储 → 应用
  ↓
RDF / OWL / 本体 / 属性图 / SPARQL / Cypher
  ↓
图数据库、爬虫、异步 I/O、推理与质量
  ↓
2025 年 5 月真题 → 变式题 → 限时案例
```

## 答题总原则

```text
先给结论
→ 解释核心概念
→ 结合题干说明原因
→ 给出技术方案
→ 说明优缺点或风险
→ 给出适用场景或评价指标
```
