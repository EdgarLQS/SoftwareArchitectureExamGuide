知识图谱考前速查

七阶段：采集 → 清洗 → 抽取 → 表示 → 融合 → 存储 → 应用
NER：找实体
关系抽取：找实体之间的联系
属性抽取：找实体自身的特征

RDF：三元组
OWL：本体和语义约束
SPARQL：查 RDF
属性图：节点+关系+属性
Cypher：查属性图

爬虫：调度 → 下载 → 解析 → 存储
异步 I/O：非阻塞 + 事件驱动 + I/O 场景提升并发

选型五句法

  1. 实体类型多、关系复杂。
  2. 需要多跳关系和路径查询。
  3. 节点、边、属性模型匹配。
  4. 便于关联分析和图算法。
  5. 仍需评估事务、规模、索引、一致性和运维成本。
