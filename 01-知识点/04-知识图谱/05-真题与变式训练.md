# 05 真题与变式训练

## 1. 2025 年 5 月案例：医院知识图谱

本地真题原文见[2025 年 5 月案例整理](../../03-案例专题/000-历年真题/2025年5月.md)。该题包含知识图谱流程图、爬虫架构与异步 I/O、图数据库选型。

### 问题一：流程图填空

核心顺序：

```text
数据源
→ 数据采集
→ 数据清洗
→ 知识抽取
   ├─命名实体识别
   ├─关系抽取
   └─属性抽取
→ 知识表示
→ 知识存储
→ 知识应用
   ├─知识检索
   ├─问题分类
   ├─模板匹配
   └─模板翻译
```

答题时重点区分：

| 易混淆项 | 正确区分 |
|----------|----------|
| 知识抽取 vs 知识表示 | 前者从数据中找知识，后者把知识编码成结构 |
| NER vs 关系抽取 | 前者找实体，后者找实体之间的联系 |
| 问题分类 vs 知识检索 | 前者判断用户意图，后者查询图谱得到结果 |
| 模板匹配 vs 模板翻译 | 前者匹配问题结构，后者把结构转换为查询 |

### 问题二：爬虫和异步 I/O

标准骨架：


```text
URL 调度器 → 网页下载器 → 内容解析器 → 数据存储器
                 ↑
              URL 去重
```

异步 I/O 必须写到三个点：非阻塞、事件/回调驱动、I/O 密集场景下提升并发和吞吐。

### 问题三：数据库选型

使用“结论—数据特征—模型匹配—查询收益—边界”五句法：

```text
结论：选择图数据库或 RDF 三元组库。
数据特征：医药实体多、关系复杂、需要多跳关联。
模型匹配：节点、边和属性天然表达实体及其关系。
查询收益：便于路径遍历、关联查询和图算法分析。
边界：若强调强事务、批量聚合或标准语义推理，应结合关系库或 RDF 库评估。
```

## 2. 变式题一：金融风控

某平台需要识别“同一设备绑定多个账号、多个账号共享收款卡”的欺诈网络。

回答要求：

1. 选择适合的数据模型。
2. 写出至少四类实体和三类关系。
3. 说明图查询比单表查询的优势。
4. 指出一个数据质量风险。

答题方向：账号、设备、银行卡、订单；绑定、登录、收款；多跳路径；实体对齐、来源可信度或时间有效性。

## 3. 变式题二：医疗知识更新

两个数据源对同一药品给出了不同禁忌信息，且更新时间不同。

回答要求：

1. 这是知识抽取问题、知识融合问题还是存储问题？
2. 设计一个冲突处理方案。
3. 如何保证答案可追溯？

答题方向：属于知识融合和质量治理；比较来源等级、发布时间、版本和专家审核；保存来源、证据、时间戳和版本。

## 4. 变式题三：开放领域图谱

互联网百科数据规模很大、领域开放、概念变化快，但初期领域专家有限。

比较自顶向下和自底向上，并说明是否可以采用混合方案。

答题方向：自底向上启动快、覆盖广但一致性风险高；自顶向下规范但成本高；可以用已有本体约束核心概念，再用数据驱动扩展候选知识。

## 6. 评分规则

```text
先给结论：是否答到题目要求
再给理由：是否结合题干数据特征
再给方案：组件、流程、技术和控制措施是否完整
最后给边界：是否说明优缺点、风险或适用条件
```
