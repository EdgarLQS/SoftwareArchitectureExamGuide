## 二、首批待验证问题

- [ ] Redis “单线程模型”在不同版本和不同线程任务上的准确表述。
- [ ] RDB、AOF、混合持久化的恢复和数据丢失边界。
- [ ] 主从复制部分重同步、复制积压缓冲区和故障切换。
- [ ] Sentinel、Cluster 与持久化之间的能力边界。
- [ ] Redis 分布式锁与 RedLock 的适用边界，不写成绝对安全结论。
- [ ] 大 Key、热 Key 和内存淘汰策略的真实实验现象。

## 三、学习记录原则

只有在完成实验、独立回答问题、纠正误解或明确披露已有掌握程度后，才把内容升级为稳定知识。未来产生正式学习记录时，可在本文件保留链接，并按教学技能的 `0001-<slug>.md` 规则建立 `learning-records/` 目录。
