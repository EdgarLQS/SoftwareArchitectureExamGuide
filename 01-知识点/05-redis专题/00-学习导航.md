## 二、零基础先建立四个模型

1. **数据模型**：Key 指向一个 Redis 数据结构；先判断数据关系和操作，再选择类型。
2. **访问模型**：缓存是数据库前面的加速层，不自动等于数据源；必须设计未命中、更新和失效流程。
3. **故障模型**：内存、进程、节点、网络和数据库都可能失败；高可用不是持久化的同义词。
4. **考试模型**：答案不能只写产品名，要写“问题 → 原因 → 方案 → 机制 → 取舍 → 故障兜底”。

## 三、每次学习的固定动作

- 学前：不看答案，写出本节已知内容和一个疑问。
- 学中：只记录能解释“为什么”的机制，不抄整段资料。
- 学后：完成一个命令实验或一道场景题，并写出结果。
- 复习：在 D0、D+2、D+7、D+21 重新回忆，错误写入 [错题记录](./07-错题与学习记录.md)。

## 四、第一周建议任务

1. 阅读本导航和 `01-Redis专题复习指南.md` 的概述、数据结构章节。
2. 完成实验文档中的 String、Hash、Set、ZSet 和 TTL 实验。
3. 不看资料回答：为什么商品详情适合 Hash，排行榜适合 ZSet，计数器适合 String？
4. 将不会解释的内容记录到错题文件，不急着背诵。
