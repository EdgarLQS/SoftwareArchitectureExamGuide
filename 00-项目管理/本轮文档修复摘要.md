# 本轮文档修复摘要

> 工作分支：`agent/fix-documentation-consistency`
>
> 约束：不创建 PR，不修改或合并 `main`。

## 一、治理目标

本轮工作已从“继续增加资料”转为建立一套可信、可维护、可执行的备考知识库，主要处理：

- 案例计分、得分率和选答口径冲突；
- 题面完整性、个人训练和答案来源混写；
- 当前批次与历史资料混用；
- 论文固定模板、伪精确评分和模拟数据冒充实测；
- 架构技术概念、事务边界和指标因果链错误；
- 当前入口、历史稿和重复文件边界不清；
- 知识点长文版本过旧、绝对化结论和不安全代码示例；
- 缺少自动化文档质量门禁。

## 四、知识点长文进展

已建立：

- [知识点当前入口](../01-知识点/README.md)；
- [Redis 与缓存架构当前复习指南](../01-知识点/03-Redis%20专题-2026H2.md)；
- [Redis 历史长文核验说明](../01-知识点/03-Redis%20专题-核验说明.md)。

Redis 当前指南已按当前官方文档和仓库技术口径重构，重点修正：

- 不再固定为“只有五种数据类型”或固定吞吐量；
- 区分核心命令事件循环、I/O 线程、后台线程和子进程；
- RDB/AOF 的 RPO、RTO、Fork 和 fsync 边界；
- 异步复制、Sentinel 和故障转移的数据窗口；
- Redis Cluster 使用 16384 个 Hash Slot，不与一致性哈希混写；
- 分布式锁使用唯一 token、有限租约、安全释放和 fencing 思路；
- RedisBloom 能力、容量和假阳性边界；
- Cache-Aside、穿透、击穿、雪崩和一致性分级；
- Binlog 失效是异步最终一致，双写不是天然强一致；
- 热点 Key、大 Key、库存预扣、幂等补偿和容量监控。

历史 `03-Redis 专题.md` 继续保留命令与例题素材，但不再作为默认背诵入口。

## 六、自动化质量门禁

当前分支新增：

```text
00-项目管理/docs-current-manifest.txt
scripts/check_current_docs.py
.github/workflows/docs-quality.yml
```

校验范围包括：

- 当前文档是否存在；
- Markdown 相对链接是否有效；
- YAML 元信息是否完整；
- 文档 ID 是否重复；
- 模拟论文是否声明模拟数据；
- 得分率是否符合 `得分 ÷ 满分`；
- 是否重新出现错误案例计分文本；
- 九个案例批次是否都有核验说明；
- 11 个论文专题是否都有记忆卡、框架和唯一主范文。

GitHub 连接器暂未返回可确认的 Actions 最终运行状态，因此不能宣称工作流已经在线通过；当前规则已进行静态复核。
