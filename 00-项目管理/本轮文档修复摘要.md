## 四、论文技术纠错

### 软件架构风格

- Cache-Aside 写路径改为更新数据库并提交后删除缓存；
- CAP 不再简化为直接选择 AP；
- 增加读己之写、副本延迟和混合架构权衡。

### 多元异构数据集成

- CDC 不再描述为完全零侵入；
- 数据联邦不再描述为天然拖垮源库；
- 区分 Schema 演进和业务语义变化；
- LLM 辅助映射增加评估集和人工审批。

### 测试

- 不再使用唯一固定测试分类；
- 删除通用 TPS 公式和固定资源阈值；
- 连接池按数据库容量和实例数计算；
- 自动化和 AI 测试增加维护、评估和人工审核边界。

### 微服务

- 服务边界基于业务能力、数据所有权和事务；
- 不从事件数量机械推导服务数量；
- 跨服务流程增加 Outbox、幂等、补偿和状态查询；
- 数据库物理分离采用渐进迁移。

### 云原生

- 云原生改为能力模型，不宣称唯一四大支柱；
- 区分 Startup、Readiness 和 Liveness；
- PDB 不再描述为所有故障下的高可用保证；
- HPA 增加数据库连接和下游容量预算；
- 增加镜像供应链和制品签名。

### ABSD

- ABSD 活动组织不再宣称唯一固定六阶段；
- Outbox 业务数据和事件保持同库同事务；
- 盲索引只用于受限查询；
- 增加 ADR、架构一致性和运行反馈。

### 系统安全

- JWT 只作为令牌格式，不描述为天然安全或完全无状态；
- 密码使用专用慢哈希；
- MFA 按风险和因素类型设计；
- 增加资源级授权、密钥生命周期、供应链和恢复；
- 删除“零安全事件”证明绝对安全的结论。

### 软件维护

- 删除无来源的维护比例和生命周期成本比例；
- 质量阈值按模块和风险校准；
- 可靠性指标使用一致统计窗口；
- 技术债按风险和价值治理。

### SOA

- SOA 不再等同 SOAP、Web Service 或 ESB；
- ESB 不再描述为必然单点；
- 契约增加版本、兼容、SLO 和生命周期；
- 跨系统一致性增加幂等、补偿和人工兜底。

### 大数据

- Checkpoint 不再直接等同端到端 Exactly-Once；
- 完整说明 Watermark 和迟到数据；
- 背压先定位慢算子和外部 Sink；
- 湖仓不再描述为自动消除所有双链和语义问题。

### 性能优化

- 高并发题不再机械要求六方向全部展开；
- 建立基线后再优化；
- 应用扩容考虑数据库、缓存、消息和外部 API 容量；
- 统一阶段指标，避免优化后数据反向变化。
