## 文档维护原则

1. 官方考试事实与个人训练方法分开记录。
2. 历年题面完整性必须明确，不把整理版视为完整原卷。
3. AI 辅助内容必须标注并经过人工核对。
4. 论文中的模拟项目和量化指标不得冒充真实项目测量结果。
5. 内容修改后同步检查索引、相对链接、适用考试批次和最近核验日期。
6. 过期内容保留历史价值时应标记为 `deprecated` 或移动到归档目录，不继续作为当前入口。
7. 当前入口优先保持简洁，技术细节留在对应专题中维护。
8. 历史资料不因当前考试批次变化而被无差别覆盖；应区分创建背景和当前适用范围。
9. 内部评价量表只能用于训练复盘，不得转换为确定的官方考试分数。

## 推荐状态

```text
draft → structured → reviewed → verified
                         ↓
                    deprecated → archived
```

| 状态 | 含义 |
|------|------|
| `draft` | 草稿，结构和事实可能不完整 |
| `structured` | 已完成结构化整理，尚未全面复核 |
| `reviewed` | 已人工核对主要内容 |
| `verified` | 关键事实已通过官方资料、真题或权威来源验证 |
| `deprecated` | 已过期，不再作为当前备考依据 |
| `archived` | 仅作为历史资料保留 |

## 当前工作分支

文档一致性修复统一在以下分支进行：

```text
agent/fix-documentation-consistency
```

该分支暂不创建 PR，不合并到 `main`，待维护清单中的当前阶段任务完成并完成差异复核后再决定后续处理。
