## 历史范文

以下文件保留历史价值，但不再作为当前默认范文：

- `03-高并发系统设计论文范文-通用版.md`
- `03-性能优化论文范文-通用版.md`

历史文件可能包含：

- 固定“六方向必须全部展开”的要求；
- 多套不一致的 QPS、P99 和可用性指标；
- 把工具或中间件清单当作架构设计；
- 应用扩容未考虑数据库连接和下游容量；
- Cache-Aside、消息一致性或连接池边界表达不完整；
- 未明确标记模拟项目和模拟数据。

使用历史文件时必须以当前记忆卡、写作框架和主范文为准进行核对。

## 当前统一指标

| 指标 | 基线 | 扩容后 | 异步后 | 最终 |
|------|------|--------|--------|------|
| QPS | 500 | 6000+ | 6000+ | 6000+ |
| P99 | 8 秒 | 1.2 秒 | 600ms | 400ms |
| 主链路 | 1050ms | 1050ms | 65ms | 65ms |
| 可用性 | 95% | 99.5% | 99.9% | 99.99% |
| 主库 CPU | 95% | 90% | 85% | 45% |
| 慢查询 | 1200 条/日 | 1200 | 1200 | 少于 15 |

全部为论文训练用模拟数据。

## 使用原则

```text
先建立性能基线
→ 根据题目选择最相关方向
→ 保护系统
→ 扩展容量
→ 异步缩短主链路
→ 治理数据库根因
→ 在相同条件下复测
```

高并发题不一定要求机械展开全部六个方向。缓存题、数据库题、限流题和性能测试题应聚焦题目指定范围。
