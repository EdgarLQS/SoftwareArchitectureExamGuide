# 论文专题当前入口

> 当前适用批次：`2026-H2`。本文件位于论文目录最前面，用于避免进入历史模板、旧评价报告或未迁移范文。

## 一、使用入口

1. [论文专题总览](./README.md)：复习主线和专题目录。
2. [当前范文导航](./当前范文导航.md)：11 个专题当前推荐主范文。
3. [论文专题故事线导航](./论文专题总览与故事线导航.md)：六条高频主线和模板选择。
4. [论文写作通用训练模板](./论文写作通用套路模板.md)：审题、结构、架构决策和限时训练。
5. [论文审查与改进工作流](./论文优化改进模板.md)：技术审查、指标一致性和 P0/P1/P2 修订。
6. [论文训练评价规范](../00-项目管理/论文训练评价规范.md)：内部等级，不换算官方分数。

## 二、标准训练顺序

```text
原始题目
→ 00-大纲记忆卡
→ 02-论文写作框架
→ 当前主范文
→ 脱稿提纲
→ 120 分钟全文
→ 技术与指标复盘
→ 更新错题和记忆卡
```

## 三、当前规则

- 题目要求优先于固定模板。
- 不强制五段、固定字数、固定过渡句或固定“我/我们”次数。
- 内部评价只使用 `stable / usable / revise / avoid`。
- 不使用 `71/75`、`75/75` 或“70+ 分标准”作为确定结论。
- 所有通用范文项目与量化指标均为模拟数据。
- AI 辅助内容需要人工核对，不能直接标记为 `verified`。
- 技术方案必须说明前提、限制、副作用、故障和恢复。
- 记忆卡、写作框架和当前范文使用同一指标口径。

## 四、历史资料

专题目录中可能保留：

- 旧版范文；
- 技术参考版；
- 旧评价报告；
- 2026 年上半年创建的模板；
- 固定段落和固定分值规则。

除非文件已在[当前范文导航](./当前范文导航.md)中列为主范文，否则使用前必须与当前记忆卡、写作框架和评价报告核对。
