## 历史资料说明

目录中其他测试知识点、故事线和旧范文继续保留，但可能包含固定分类、固定阈值、固定 TPS 公式和旧考试批次。当前使用时以本 README、记忆卡和统一框架为准。

## 重点纠错

- 性能测试不只有唯一固定四类；
- P99 和资源利用率阈值必须来自业务 SLO 与容量测试；
- 不使用“80/20 × 3 倍”作为通用 TPS 公式；
- 数据库连接池不是越大越好；
- 自动化测试不能完全替代探索性和人工验收；
- 覆盖率不是测试质量的唯一指标；
- AI 生成用例需要评估集、隐私控制和人工审核。
