## 当前技术口径

- 云原生是一组交付和运行能力，不等同于 Kubernetes，也没有唯一固定“四大支柱”；
- Startup、Readiness 和 Liveness 探针承担不同职责；
- PDB 只约束计划内驱逐，不保证任意故障下的高可用；
- HPA 必须受数据库连接、缓存、消息和第三方接口容量约束；
- 当前主范文包含镜像扫描、SBOM、签名、最小权限和密钥治理；
- 容器化不自动降低成本，仍需容量、SLO 和 FinOps 治理。
