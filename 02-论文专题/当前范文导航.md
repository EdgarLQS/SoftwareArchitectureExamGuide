## 二、使用顺序

```text
阅读题目
→ 查看对应记忆卡
→ 使用写作框架建立题目映射
→ 阅读当前主范文的因果链
→ 脱稿列提纲
→ 120 分钟完成新题
→ 按论文训练评价规范复盘
```

范文只提供素材和表达方式，不能整篇机械背诵。新题中应重新判断：

- 题目要求哪些理论、方法或比较；
- 项目背景是否真正支持该技术；
- 哪些实践最能回应题目；
- 哪些指标能够被措施解释；
- 哪些限制和权衡必须说明。

## 三、当前统一规则

所有当前主范文均应满足：

- YAML 元信息包含 `2026-H2`；
- `source_level` 包含 `reference` 和 `ai_assisted`；
- `scenario_data` 标记为 `simulated`；
- 不使用确定性官方分数；
- 不把固定段数、字数或句式作为官方硬规则；
- 关键技术说明前提、限制和副作用；
- 指标与记忆卡和写作框架保持一致；
- 正文能够使用纯文字完成。

## 四、历史文件处理

专题目录中可能仍保存旧范文、技术参考版或旧评价报告。处理规则：

1. 本导航列出的文件为当前主范文。
2. 文件名包含 `2026H2` 的新范文用于避免覆盖历史稿。
3. 已经原路径重写的范文继续沿用原文件名，保证历史链接可用。
4. 旧评价报告若标记 `deprecated`，只用于兼容历史链接。
5. 历史范文中的技术内容使用前必须与当前记忆卡、框架和评价报告核对。
6. 后续完成迁移后，再决定是否移动到 `99-归档/`。
