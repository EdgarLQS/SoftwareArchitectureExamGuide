## 当前技术口径

- CDC 减少业务代码侵入，但仍有日志、快照、权限和资源成本；
- 数据联邦适合受控的低频查询，不应无边界把重查询压到源库；
- Schema 演进只能处理部分结构变化，不能自动解决业务语义变化；
- LLM 只生成字段或术语映射候选，生产发布必须经过评估和人工审批；
- 实时链路需要处理重复、乱序、迟到、回放和对账。
