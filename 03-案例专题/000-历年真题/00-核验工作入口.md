## 四、工作流

```text
发现问题
→ 在逐年核验说明登记
→ 保存来源和定位信息
→ 建立专项修复记录
→ 双重校对题面
→ 标记答案来源等级
→ 补录 selected_questions
→ 新建或版本化评分记录
→ 更新两份总账
```

## 五、完成标准

单个年份完成核验至少满足：

- [ ] 原始题量和选答说明可定位
- [ ] 题面、图表和分值完整或明确缺失区域
- [ ] 本次计分的选答题已记录
- [ ] 每道参考答案有来源等级
- [ ] 分数和得分率数学一致
- [ ] 评分变更保留旧值和依据
- [ ] AI 辅助内容经过人工复核并明确标记
- [ ] 对应逐年说明和两份总账同步更新

## 六、禁止事项

- 不用相邻年份题目补缺题；
- 不凭答案反推完整原题；
- 不把 OCR 或 AI 输出直接当作原题文本；
- 不覆盖历史成绩而不保留版本；
- 不把来源不明答案升级为官方答案；
- 不在题面不完整时计算精确命题频率。
