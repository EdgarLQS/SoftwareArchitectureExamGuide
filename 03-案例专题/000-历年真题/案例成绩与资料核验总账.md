# 案例成绩与资料核验总账

> 本文件统一记录当前仓库中的个人案例训练成绩、得分率和题面完整性。它不是官方成绩单，也不证明对应年份题面或答案已经完整核验。

## 一、统一计分口径

```text
模拟考试成绩 = 本次明确选答的 3 道题得分之和
总分 = 3 × 25 = 75
得分率 = 得分 ÷ 75 × 100%
```

为了学习而完成的其他备选题属于专项训练，不应累加进同一次 75 分模拟成绩。

### 数学核验

```text
36 ÷ 75 = 48.0%
38 ÷ 75 = 50.666...% ≈ 50.7%
55 ÷ 75 = 73.333...% ≈ 73.3%
26 ÷ 75 = 34.666...% ≈ 34.7%
28 ÷ 75 = 37.333...% ≈ 37.3%
42 ÷ 75 = 56.0%
40 ÷ 75 = 53.333...% ≈ 53.3%
45 ÷ 75 = 60.0%
```

当前表内得分率均按一位小数重新计算，没有继续沿用历史文件中可能存在的错误百分比。

## 三、统计解释

### 3.1 全部记录

九次记录总分为：

```text
36 + 38 + 38 + 55 + 26 + 28 + 42 + 40 + 45 = 348
```

平均成绩：

```text
348 ÷ 9 ≈ 38.7/75
平均得分率 ≈ 51.6%
```

该平均值混合了资料完整和资料不完整的年份，只能用于粗略观察，不能作为稳定能力的唯一判断。

### 3.2 最近三次记录

```text
2024 下：42
2025 上：40
2025 下：45
平均：(42 + 40 + 45) ÷ 3 ≈ 42.3/75
```

最近三次平均仍低于当前案例安全目标 50 分，说明需要通过专题迁移和错题回归提高稳定性，而不是继续无边界收集资料。

### 3.3 最好成绩

2022 下记录为 55/75，说明在部分题型和知识组合下具备达到目标的能力。后续复盘应比较 2022 下与低分年份的：

- 选题策略；
- 熟悉专题；
- 审题和关键词覆盖；
- 图表题表现；
- 时间分配；
- 答案来源和评分严格度。

不能只用单次 55 分推导“已经稳定通过”。

## 四、完整性与可信度

| 状态 | 能否用于完整 90 分钟模拟 | 能否用于专题训练 | 需要补充 |
|------|--------------------------|------------------|----------|
| 当前记录较完整 | 可以，但仍需核验原始题面和分值 | 可以 | 来源、题面、答案与评分依据 |
| 部分图片或缺题 | 不建议作为唯一整套模拟 | 可以训练已有题目 | 图片文本化、缺失题和分值 |
| 整理版未核验 | 不作为正式整套成绩 | 可作知识点练习 | 原始题面、图片、分值和答案来源 |

特别说明：

- 2024 上的 28/75 不能与完整原卷成绩等量比较；
- 2025 上的 40/75 受图片和题面缺失影响；
- 2023 下缺少第 3 大题，选题空间与完整试卷不同；
- 不同年份评分可能使用官方答案、机构解析或 AI 辅助参考答案，严格度可能不一致。

## 五、正式考试记录与训练记录分离

仓库中另有两次正式考试的三科记录，但本总账不在无法确认批次和成绩单来源时将其强行映射到具体年份。正式考试成绩应单独保存：

```text
批次
→ 综合知识
→ 案例分析
→ 论文
→ 成绩来源或截图
→ 是否通过
```

个人训练成绩不得标记为正式考试成绩，正式成绩也不应覆盖训练过程中的逐题记录。

## 六、后续逐年核验字段

每个年份完成核验后，补充：

| 字段 | 内容 |
|------|------|
| `exam` | `YYYY-H1` 或 `YYYY-H2` |
| `question_source` | 原始题面、截图或可核验出处 |
| `completeness` | complete / partial / image_only / reconstructed / missing |
| `selected_questions` | 本次明确计分的题目编号 |
| `score_basis` | 官方答案 / 权威解析 / 参考答案 / AI 辅助人工复核 |
| `score` | 选答题总分 |
| `rate` | 自动计算得分率 |
| `reviewed_at` | 最近复核日期 |
| `open_gaps` | 缺题、缺图、分值或答案分歧 |

## 七、当前训练目标

```text
最近三套案例平均 ≥ 50
最近两套案例均 ≥ 50
90 分钟内完成三道选答题
D+21 旧错题回归通过率 ≥ 80%
```

目标来源于当前个人备考计划，不是官方合格标准。
