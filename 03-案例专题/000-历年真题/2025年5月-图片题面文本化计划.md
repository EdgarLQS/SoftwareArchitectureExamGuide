# 2025 年 5 月案例图片题面文本化计划

> 当前状态：原训练文件的部分题目依赖图片，尚不能作为完整可检索题面。本计划只定义整理流程，不补写或猜测图片内容。

## 一、目标

形成一份可检索、可引用、可逐题评分的文本资料，同时保留原始图片和定位信息：

```text
原始图片
+ 原样转写文本
+ 图表结构化描述
+ 人工校对记录
+ 题目和答案来源
+ 完整性状态
```

## 二、禁止事项

- 不凭上下文补齐看不清的文字；
- 不把模型识别结果直接写成原题；
- 不删除原图片或来源链接；
- 不把示意图改画后当作原图；
- 不在题面未完整前重新计算正式模拟成绩；
- 不把人工推断答案称为官方答案。

## 三、处理流程

### 3.1 资产盘点

为每张图片登记：

```yaml
asset_id: 2025H1-Q2-IMG01
question_no: 2
subquestion_no: unknown
repository_path: 待补录
source_url_or_file: 待补录
page_or_region: 待补录
resolution_status: readable | partial | unreadable
contains:
  - question_text
  - architecture_diagram
  - table
  - code
  - answer
```

### 3.2 原样转写

- 按图片顺序逐行转写；
- 保留题号、括号、空格编号、分值和选答说明；
- 看不清内容用 `[无法辨认]`，不猜字；
- 数学符号、箭头、表头和图例单独校对；
- 转写文本与解释性备注分开。

### 3.3 图表描述

对架构图和流程图同时保存：

1. 节点原始文字；
2. 连线方向；
3. 箭头或数据流标签；
4. 图中空格编号；
5. 布局和层次；
6. 无法辨认区域。

可重绘 Mermaid 或 ASCII 图用于检索，但必须标记为“人工重绘”，并与原图并存。

### 3.4 双重校对

```text
第一次：转写人与原图逐字核对
→ 第二次：另一轮独立校对或隔日复核
→ 差异登记
→ 确认版本
```

校对记录：

```yaml
transcription_version: v1
transcribed_by: 待补录
first_checked_at: YYYY-MM-DD
second_checked_by: 待补录
second_checked_at: YYYY-MM-DD
unresolved_regions:
  - asset_id + 区域描述
```

### 3.5 题面组装

按照原卷顺序组装：

```text
卷首说明
→ 题量与选答规则
→ 第 1 大题
→ 第 2 大题
→ ……
→ 每题分值与图表
```

在卷首和题量未确认前，文件状态保持 `partial`。

## 四、验收标准

题面可以升级为“文本较完整”必须同时满足：

- [ ] 所有已知图片均已登记
- [ ] 所有可见文字完成原样转写
- [ ] 题号、分值和空格编号完成二次校对
- [ ] 图中节点和连线可被定位
- [ ] 卷首选答规则已确认或明确缺失
- [ ] 无法辨认区域单独列出
- [ ] 原图路径和来源仍可访问
- [ ] 转写文本与参考答案分离

升级为“完整原卷依据”还需要核对官方或可信原始试卷来源。
