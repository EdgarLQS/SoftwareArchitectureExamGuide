# 2019 年 11 月案例估分冲突处理记录

> 已知问题：原训练文件第 1 大题某小题的正文估分与文件末尾总评不一致。当前总账暂按历史末尾总评 `36/75` 保存，但冲突尚未解决。

## 一、当前采用值

```yaml
year_session: 2019-H2
score_total_current: 36
score_maximum: 75
score_rate: 48.0%
score_status: conflicted
selected_questions: 待补录
adopted_from: 历史文件末尾总评
```

当前采用值只用于保持历史统计连续性，不代表已验证的正确评分。

## 二、冲突信息

| 项目 | 当前状态 |
|------|----------|
| 冲突位置 | 第 1 大题某小题正文估分 vs 文件末尾总评 |
| 正文估分值 | 待从原文逐项抄录 |
| 总评采用值 | 36/75 |
| 选答题 | 待补录 |
| 参考答案来源 | 待核验 |
| 是否影响总分 | 很可能，需要逐小题重算 |

禁止在未抄录原始分项值前猜测差额来源。

## 三、处理流程

1. 从 `2019年11月.md` 抄录每个小题：满分、历史得分、评语和答案来源；
2. 明确当次三个计分题；
3. 计算：

```text
每题得分 = 该题计分小题得分之和
总分 = selected_questions 对应题目得分之和
得分率 = 总分 ÷ 总满分 × 100%
```

4. 与末尾总评 36/75 比较；
5. 如果历史正文有明显算术错误，建立新评分版本，不覆盖旧值；
6. 如果差异来自评分标准变化，保存旧/新答案版本和理由；
7. 更新逐年核验说明、成绩总账和答案来源总账。
