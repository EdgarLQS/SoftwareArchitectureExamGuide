# 2023 年 11 月案例第 3 大题补录计划

> 当前仓库缺少第 3 大题。本计划定义来源检索、题面核验和成绩处理方法，不根据其他年份考点猜题。

## 一、补录目标

形成可追溯的第 3 大题资料：

```text
原始题面或可信扫描件
+ 题号、材料、小题和分值
+ 图表/代码/表格
+ 来源和定位信息
+ 文本转写及校对
+ 参考答案来源
+ 与原训练成绩的关系说明
```

## 二、来源优先级

1. 官方试卷、考试机构发布或可核验官方存档；
2. 正式出版教材、历年真题集和可定位页码；
3. 权威培训机构保留的完整试卷扫描；
4. 多个独立来源一致的题面；
5. 单一网络转载，只能作为线索，不能直接升级为已核验题面。

禁止通过以下方式补题：

- 根据同年其他题目推断；
- 根据常见考点自行编题；
- 复制相邻年份第 3 大题；
- 仅凭答案反推完整题干；
- 使用 AI 补全缺失材料并当作原题。

## 四、题面核验步骤

### 4.1 结构确认

- 是否确实标为第 3 大题；
- 材料是否完整；
- 小题数量和编号；
- 每小题分值与总分；
- 是否有图、表、代码或附件；
- 是否存在选答或替代说明。

### 4.2 多来源比对

至少比较：

- 题干文字；
- 专有名词和版本；
- 空格编号；
- 图中节点和连线；
- 小题分值；
- 页面顺序。

差异不能静默合并，应登记来源 A/B 的不同文字并说明当前采用版本。

### 4.3 文本化与校对

图片或 PDF 转写时保留原文件，无法辨认位置写 `[无法辨认]`。完成两轮校对后再合入 `2023年11月.md` 或建立单独的题面文件。

## 五、答案处理

补齐题面和补齐答案是两个独立任务。

答案来源按以下等级标记：

```text
official
→ authoritative_analysis
→ cross_verified_reference
→ reference
→ ai_assisted
→ unknown
```

技术答案还需与当前专题指南核对，例如数据库、缓存、流批架构或嵌入式题中的版本差异。

## 六、对历史成绩的影响

当前 26/75 是基于已记录选答题的个人训练估分。补齐第 3 大题后：

- 不自动修改原历史成绩；
- 若第 3 大题不是当次选答题，只作为新增专项训练；
- 若证据表明原训练本应计入第 3 大题，则建立新 attempt 版本并保留旧值；
- 必须补录 `selected_questions` 后才能判断是否需要重算；
- 新旧成绩注明题面版本、答案版本和评分日期。

## 七、验收标准

- [ ] 找到至少一个可定位来源
- [ ] 确认题号、小题和分值
- [ ] 图表和材料完整或明确缺失区域
- [ ] 完成两轮文本校对
- [ ] 保存来源和版本信息
- [ ] 参考答案与题面分离
- [ ] 补录选答题后再处理成绩
- [ ] 更新 2023 年核验说明和总账
