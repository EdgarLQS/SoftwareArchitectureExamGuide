## 二、答案标签解释

历史原文中的以下标题不能直接理解为官方结论：

```text
补充答案（标准参考）
标准答案
全部正确
```

在完成来源核验前，统一解释为：

```text
参考答案（来源待核验，可能含人工或 AI 辅助整理）
```

答案升级为 `official` 或 `verified` 至少需要保存以下证据之一：

- 官方发布的题面或答案；
- 可定位页码的权威出版物；
- 可复核的机构解析，并说明机构和版本；
- 多来源交叉验证及人工技术复核记录。

## 三、训练规则

1. 开始训练前确认该年原始题量和选答要求。
2. 明确记录本次计分题，其他题只作为专项训练。
3. 总分和得分率使用[评分模板](./评分模板.md)计算。
4. 题面缺失、图片不完整或人工重构时，不标记为完整原卷模拟。
5. 技术答案与当前专题资料冲突时，以已复核的当前专题口径为准，并登记冲突。
6. 评分发生变化时保留旧值、修改原因和依据，不只覆盖最终数字。
