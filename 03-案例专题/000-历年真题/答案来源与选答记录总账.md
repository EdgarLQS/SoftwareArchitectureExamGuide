## 二、答案来源等级

| 标签 | 使用条件 | 是否可称“标准答案” |
|------|----------|----------------------|
| `official` | 官方机构发布并保存可定位链接或文件 | 可以注明官方，但仍需核对版本 |
| `authoritative_analysis` | 权威出版物或培训机构解析，可定位出版物、页码或版本 | 不称官方答案 |
| `cross_verified_reference` | 至少两个独立来源一致，并经人工技术复核 | 称交叉核验参考答案 |
| `reference` | 来源不完整、单一解析或历史整理 | 只能称参考答案 |
| `ai_assisted` | AI 生成或补全，已/未人工复核需另行标记 | 不能称标准或官方答案 |
| `unknown` | 无法识别来源 | 必须降级，禁止据此精确评分 |

## 三、每道题的来源记录格式

```yaml
year_session: 2024-H2
question_no: 1
subquestion_no: 2
source_level: reference
source_title: 待补录
source_locator: 待补录
retrieved_at: YYYY-MM-DD
answer_version: v1
review_status: unverified | reviewed | verified
reviewer: 待补录
conflicts:
  - 无 | 冲突描述
notes: 适用版本、假设和技术边界
```

对图片答案还应记录：

```yaml
image_path: 仓库相对路径或来源文件
image_page_or_region: 页码/区域
transcribed_by: 人工
transcription_checked_by: 第二人或二次复核
```

## 四、选答记录格式

每次限时模拟必须先写：

```yaml
attempt_id: 2026-08-01-case-01
year_session: 2024-H2
attempt_type: full_mock | partial_mock | topic_practice | review
available_questions: [1, 2, 3, 4, 5]
selected_questions: [1, 3, 4]
score_by_question:
  1: 14
  3: 13
  4: 15
score_total: 42
score_maximum: 75
duration_minutes: 90
question_completeness: complete | partial | reconstructed
answer_source_status: mixed
```

规则：

- `score_total` 必须等于选答题得分之和；
- 未选题不进入本次 75 分成绩；
- 额外完成题放入 `topic_practice`；
- 资料不完整时使用 `partial_mock`，不能标记完整原卷模拟；
- 原卷题量未知时，`available_questions` 写 `unknown`，不猜测。

## 五、历史原文替换规则

原文出现：

```text
补充答案（标准参考）
标准答案
全部正确
```

在没有官方证据前应改为：

```text
参考答案（来源待核验）
```

评分结论改为：

```text
基于当前参考答案的训练估分，不代表官方阅卷结果。
```

不能只做全局文本替换，还需逐题补来源、版本和冲突记录。

## 六、冲突处理

当不同来源不一致时：

1. 保存所有来源，不覆盖原值；
2. 比较题干版本、软件版本和假设；
3. 优先核对官方题面和教材语境；
4. 对技术问题使用官方标准、规范或产品文档复核；
5. 给出当前训练采用值及理由；
6. 评分总账标记 `conflicted`；
7. 未解决前不升级为 `verified`。
