## 使用与计分说明

- 不同年份的试卷题量可能不同，必须以对应年份原始题面中的选答要求为准。
- 项目当前模拟训练按“选答 3 道大题、每道 25 分、总分 75 分”记录。
- 为了学习而完成的其他备选题，只记录为专项训练成绩，不与本次 75 分模拟成绩累加。
- 统一评分、答案来源和 D+2/D+7/D+21 回归方法见[真题评分与错题回归模板](./000-历年真题/评分模板.md)。

## 资料完整性说明

本目录混合保存原始题面整理、图片引用、人工重构和个人作答记录，不能仅凭文件存在就判断题目已经完整核验。

| 状态 | 含义 |
|------|------|
| 完整 | 当前仓库中题面和小题结构较完整，可用于整套训练 |
| 部分缺失 | 某些大题、小题或题面材料缺失 |
| 图片引用 | 仓库只有图片或图片链接，尚未完成可检索文本整理 |
| 整理版未核验 | 根据零散资料整理或重构，不能视为完整原始试卷 |

当前已知情况：

- **2024 年 5 月**：原始题面来源不完整，现有文件包含整理或重构内容，统一标记为“整理版未核验”，不再同时使用“全部占位符”和“部分完整”两种互相冲突的表述。
- **2025 年 5 月**：第 2 大题部分内容和第 4 大题主要依赖图片引用，文本资料不完整。
- **2023 年 11 月**：缺少第 3 大题。
- 其他年份按当前仓库记录为较完整，但引用、题目文字和评分答案仍应继续核对来源。
